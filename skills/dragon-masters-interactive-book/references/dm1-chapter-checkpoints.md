# DM1逐章制作检查表

这是根据已确认制作经验提取的检查目标，不是原书转录或事实证据。每一行必须用使用者实际提供的Book 1核实并补页码。若仅提供一个章节，其余保持待补；不能从此表扩写缺失正文。角色参考缺失时，外观不自动视为已确认。

| 章 | 必须核查并落实的制作重点 | 常见偏差与检查 |
|---|---|---|
| 1 | 地点链、目的地、向下进入和章末危险分别有状态 | 不能在田野背景要求点城堡楼梯；到新地点再给操作 |
| 2 | 工作室、龙石、收好物品、提醒与理解检查 | 不发明充能/雕刻玩法；人物身份与胡须一致 |
| 3 | 逐步认识三组孩子与龙 | 身份/颜色/身体结构不能互换；不提前揭示下一章对象 |
| 4 | 暗处特征观察、佩戴后的反应、命名、门与跟随结尾 | 不用长按给龙石充电；Quiz之后仍要完成当章必要事件 |
| 5 | 各条龙展示及未成功尝试的情绪变化 | 不把失败训练做成惩罚；题目不要复制旁边刚显示的答案 |
| 6 | 食物容器、放置、信的构思与发送 | 只有一个可移动容器；信的想法不能冒充固定事件顺序 |
| 7 | 用餐结束、入睡、梦中观察、爆炸、惊醒分开 | 不随意拖月亮/划线醒来；不提前解释梦的真相 |
| 8 | 三种飞行方式、地面互动、龙石反应 | 实物sprite沿不同固定轨迹；不把描线当飞龙；地面角色不升空 |
| 9 | 桌上信件、读与放下、后续低语 | 不发明第二封信；物品数量和人物身份保持 |
| 10 | 照顾、触碰、回忆线索、返回与安慰 | 命中真实链条/士兵，不让龙头充当士兵线索；拥抱要有画面结果 |
| 11 | 写字活动、佩戴的石头、夜间人物 | 不多画桌上龙石，不提前发光；纸张不能遮住人物脸 |
| 12 | 确认同行者、经过人物、唤醒、入口警告 | 完整呈现当时角色；警告后的动作与下一章进入衔接 |
| 13 | 实际进入、异常物体、惊吓和坍塌 | 进入必须换地点；坍塌是故事事件，不归咎操作失败 |
| 14 | 黑暗、白光、失败办法、道歉、力量显现 | 白光不是常亮激光；光源位置核书；此时障碍不能提前消失 |
| 15 | 专注、碎石、尘土散去、通道、拥抱 | 动作前后图分清；保持同一组角色、比例和衣物状态 |
| 16 | 对外与私下叙述、能力与关系、未解线索、最终身份和合书 | 不以通用胜利页替代结尾；Quiz/刷新不能提前完成最终身份 |

## 全书横向检查

- 核实Drake、Bo、Rori、Ana、Griffith及四条龙的身份、配对、衣物、比例；将已核外观记入人物表。不把绿色魔法光当作龙的常态颜色。
- 一章一个核心交互目标，必要时有少量辅助操作；多幕用于把因果过程看清，不为每一幕强加一题。
- 保留16个章级Story Check，四个可选Retell（4/8/12/16）；Retell不挡下一章或合书。
- 保存章末与下一章开头的位置、物品、光、知识和未解问题；夜晚、梦境、回忆使用明确状态，不混成现实连续动作。
- 每章完成后仍在故事场景里进入下一段；保留短气泡和按需展开的阅读，问答时隐藏泄答内容。
- 配乐由事件推进：温暖/探索/悬疑/夜间/危险/力量/缓解，不能只按章节编号随机选曲。
- 本表不随包提供人物素材、完整书籍或私用成品；生成图与音乐不保证像素/波形一致，验收看故事与行为合同。
