# 可直接复制的制作提示词

将方括号替换为自己的材料。没有对应信息时明确写“待补”，不要让助手猜测。所有阶段遵守用户的上传与发布范围。

## A. 项目启动与分镜

```text
请用 Dragon Masters Interactive Book 制作DM1《Rise of the Earth Dragon》第一本桌面浏览器互动书。
来源：[附可读取文件及版本]；读者：[年龄、英文程度]；语言：[英文/中英]；目标：[窗口尺寸]；用途：[私用/计划公开及许可信息]；输出：[新的项目目录]。
先读取来源，输出逐章证据表：章节与页码、人物/地点、关键事实、不得提前揭示的信息。再给出整书场景表，每幕列entry、故事动作、读者操作、可见结果、观察/问题、exit与下一幕衔接。
遇到缺页或矛盾单独列出，不以摘要补剧情。不照搬固定章数或全章同一手势。
先提交三幕样章方案与角色参考计划，等我确认后再做整书图片。不要上传来源或公开任何文件。
```

## B. 角色参考图

```text
依据我提供且允许使用的资料，为[角色ID]画原创构图的角色一致性参考。
固定身份：[年龄感、肤色、脸型、发型与颜色、衣服层次、标志物、体型比例/动物结构]。
画面：中性站姿、全身、正面与侧面，光线均匀，背景简单；各视角是同一个角色，不是多个不同人。美术方向：[电影感2.5D/纸上手绘等]。不要加入文字、商标、未确认装备或后续剧情能力。
生成后逐项核对身份，列出偏差。未通过的图不得作为后续参考。保存采用的图及最终提示词。
```

## C. 分镜底图

```text
用途：16:9交互书场景底图。[参考1]只作已确认角色身份，[参考2]为场景机位。
时点：[原文定位、当前事件之前]。人物：[ID及位置/相对身高]；地点：[场景]；动作：[当前姿势]；光源：[来源/颜色/方向]；道具：[当前持有与位置]。
构图保持所有必要角色可见，顶部和底部各留少量低细节空间给UI。需要独立拖动的[道具]不要画进底图；落点为[图像百分比坐标及真实物体]。
不画[尚未发生的结果/发光/打开的门]，不改变参考角色发型衣服。不含文字、按钮、箭头、水印。输出单幅场景，不是拼图。
```

## D. 同镜头结果图与透明道具

```text
编辑目标为附图。只改变：[动作完成后的明确变化]。
保持机位、人物身份、比例、服装、背景物、地面及未受影响的光源不变。不得加入下一幕事件。不重新设计所有人物。
对照原图检查：只有允许的区域/姿势变化；如身份漂移，先修复再接入。
```

```text
为[道具]生成独立透明背景素材，角度、材质、光向与[场景参考]相符。整件物体完整，真实透明alpha，不要棋盘纹/黑底/文字，不带其他角色或背景。保存原图并检查边缘与透明通道。与场景底图不能重复出现同一道具。
```

## E. 交互与动画实现

```text
根据已确认scene表实现[幕ID]。核心故事动词为[动词]，所以采用[观察/拖动/长按/描画/清楚的进入按钮]。
坐标基于实际显示的图片矩形，不基于窗口。成功条件：[条件]；中途取消：[归位/不记完成]；结果：[图/动画/状态]；下一幕：[状态]。
先显示故事，再操作，再稳定显示结果，最后由读者进入Quiz。Quiz期间隐藏给出答案的气泡，不把完成动画瞬间吞掉。
必须处理pointercancel、失焦、快速切换语言、刷新、图片未加载和减少动态；提供键盘等效操作，不因随机抖动失败。角色只做故事要求的动作，不添加自由漫游。
```

## F. 配乐方案

```text
为以下scene表制定配乐，不用全书一首平铺：[附事件表]。
逐幕列情绪、节奏密度、音色、强弱、开始事件、变化事件、循环长度、淡化时间、结束条件。不要用响度突增代替危机感，也不要在真正脱困前播放胜利音乐。
先用本地generate_score.py生成可替换的试配，再给出更丰富编曲的通用音乐提示词。只用原创或许可明确素材，记录来源，不模仿具体歌曲。音乐不承载必要剧情，有静音、记忆偏好、用户点击后启动和隐藏页暂停。
```

## G. 修复审阅

```text
检查此交互书当前文件与实际操作，不仅检查文本：人物前后是否一致；操作对象是否真实对应画面；是否有重复道具/漂浮贴图；是否提前显示结果；地点衔接是否缺失；Quiz是否泄答；图片是否闪现；音乐是否随情节改变。
每项给出具体场景、可复现步骤、原因、最小修复及复测。未经许可不要修改无关章节。区分静态通过、真实浏览器通过、看图/听感确认和未测项。
```

## H. 本地可交付检查

```text
在全新目录复制候选，只用附带说明运行；验证不依赖原作者路径、笔记或聊天。检查所有图片/音频/脚本引用、存档、双语、键盘、长按取消、错误放置、图片失败、连续剧情和减少动态。
列出实际命令、结果、未测项和仍需人工制作的步骤。扫描个人路径、邮箱、密钥、内部记录和不应公开的素材。本次未授权发布时只准备包；已明确授权发布到指定仓库时，检查通过后完成该范围发布并核对远端。不要重新询问已经批准的相同步骤。
```

## I. 按完整工程交付

```text
逐项核对production.json、chapter-evidence.csv、scene-state-table.json和真实book/story.json。每个章节的必需事件都有来源页码、运行scene和可见结果；相邻exit/entry一致；DM1保留16个章级检查点及4个可选复述。调用validate_book.py和validate_production.py，修复真实缺口，不能通过删除必需事件或虚填QA来通过。图像/音乐/模板占位不能算制作完成。交付实际可打开book、制作记录、提示词、来历和测试报告；分别写明技术、视觉听感、教师、课堂及独立复现状态。
```
