# 音乐与情节

## 不只按章节选一首歌

以事件表驱动：探索→发现问题→行动→危机→结果。每段记mood、开始条件、结束条件、音色、节奏密度、目标音量、循环长度、淡化时间。相同mood不要在每次渲染/语言切换时重头播放。

| 情节 | 建议音色/节奏 | 避免 |
|---|---|---|
| 温暖相遇 | 稀疏拨弦、柔和低音，慢中速 | 一直高昂鼓点 |
| 好奇探索 | 留白、轻敲击/高音，悬而未决和声 | 提前胜利和弦 |
| 夜间/未知 | 低声部、慢脉冲、少量高音 | 过响恐怖惊吓 |
| 紧迫行动 | 更密节奏、短音型、小调色彩 | 简单把音量调大 |
| 力量显现 | 逐步加层、上行音型 | 结果发生前高潮 |
| 放松/团聚 | 开放和声、减小密度、温和延音 | 突然硬切静音 |

## 两条制作路线

**可复现本地路线**：`python3 scripts/generate_score.py --output <project>/audio`。标准库生成三首12秒单声道WAV草图，原创音型，无外部素材。mystery稀疏、motion较密、relief舒缓。可修改MOODS的音高、beat和gain。它展示配乐逻辑，不是管弦乐音色库；试听后决定是否替换。

**更丰富的编曲路线**：让作曲者或用户允许的音乐工具按以下提示制作，不指定某位艺人或歌曲：

```text
生成原创无歌词循环配乐，用于[读者年龄]的交互故事。
场景：[当前故事事件，不提供不必要的私人文本]；情绪：[mood]；音色：[乐器]；节奏：[速度/密度]；长度：[例如24秒]。
对话为屏幕文字，音乐不能争抢注意力。不含语音、不模仿既有歌曲、不出现突然巨大音量或惊吓。开头与结尾适合无明显断裂循环；有自然尾音。输出可下载音频并记录工具/作者、日期、使用与公开许可。
```

先试听每首，再连续试听过渡：神秘→行动→舒缓，不让变化仅存在于文件名。处理音量一致、首尾接缝、失真与明显点击。未确认外部素材公开许可时不要随代码发布。

## 页面接入

story.json顶层music映射到本地文件；每幕music为操作前/进行时，resultMusic可在commit后改变。示例用两个Audio实例约1.3秒交叉淡化，统一低音量，token取消旧淡化。开书后启动；静音记忆、隐藏页/合书停止，回到页面恢复当前状态。音乐缺失不应改变剧情完成条件。场景音效若添加，用用户手势触发、限制同时数量，不要覆盖阅读文字。

本例不包含人物配音。想增加朗读应作为独立范围：语音许可、文字一致、停止与打断、音乐压低、无声音也能完成故事。
